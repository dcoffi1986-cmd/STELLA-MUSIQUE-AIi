# STELLA MUSIC AI — prototype

Backend FastAPI, import MusicXML fonctionnel sous réserve de tests de déploiement. L'import PDF/image requiert Audiveris (non installé par ce Dockerfile). La synthèse vocale chantée SATB n'est pas implémentée. Ne pas déployer publiquement sans durcir l'API (limites, authentification, ressources et confidentialité). Le fichier Render utilise le plan starter potentiellement payant ; vérifier les tarifs avant déploiement.
